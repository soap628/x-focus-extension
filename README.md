# X Focus · RPG 任务卡（Edge 本地版 0.6.0）

打开 X，黑色留白里就会出现一张 232 像素宽的任务卡，比旧版 184 像素更易读。无需打开扩展专门的窗口。

- 两条每日任务进度：发帖、回复。
- 原创绘画风角色头像、雕花青铜边框和暗色皮革面板，采用传统奇幻 RPG 的材质表现；不使用像素画风。
- 红色发帖进度、蓝色回复进度、金色综合成长条；圆形金属头像框和升级／完成反馈。
- 综合等级同时衡量行动、总粉丝、认证粉丝、日均账号曝光和日均互动。点击等级可展开五维依据、来源和采集时间；行动仍保留发帖 +20 XP、回复 +5 XP 的反馈。
- 卡片显示粉丝、认证粉丝及曝光读数；账号本身的蓝 V 状态明确识别为已认证时显示专属徽章。
- 升级与任务完成有短暂光效，支持系统减少动态效果设置，无声音。
- 点击卡片右上角齿轮，直接修改每日目标、修正计数或暂停自动统计。
- 在任务卡齿轮和高级数据页切换简体中文／English，选择保存在本机；切换语言不影响数据、等级或收藏。
- 完成自动记录的每日目标、跨过新的每 5 级里程碑，可获得本地宝箱，收集 12 件奇幻物品；新增原创绘画风宝箱插画。
- 优先放在右侧空白；右侧放不下且左侧有空间时移到左侧。两侧都不够时收为小徽章，点击展开。
- “−”收起卡片；Edge 工具栏里的扩展图标也可展开／收起。

数据留在本机；不需要云端、X API Key 或本地服务器。

## 更新已安装的扩展

如果已经从本仓库目录加载扩展，先更新该目录中的源码，再重新加载：

1. 在 Edge 地址栏输入 `edge://extensions`。
2. 找到 **X Focus · 起号日常**，点击“重新加载 / 刷新”。
3. **刷新所有已打开的 X 标签页**。任务卡会直接出现在页面里。

如果原来从其他文件夹安装，将 `X-Focus-v0.6.0.zip` 解压并覆盖到原来的扩展目录，再执行上述步骤。**继续使用原目录并重新加载，不要卸载旧版**，这样可继续使用原扩展实例里的目标与记录。

首次安装：在 `edge://extensions` 打开“开发者模式”，选择“加载解压缩的扩展”，选中包含 `manifest.json` 的文件夹，然后刷新 X。

## 关掉浏览器后会不会重新开始

不会。目标、每日发帖／回复数量、行动经验、粉丝读数、分析数据、语言选择和宝箱收藏保存在本机 `chrome.storage.local`，关闭浏览器、刷新 X 或重启电脑不会主动清空它们。在同一 Edge 配置文件、同一个扩展实例中重新打开 X，会继续读取这些记录。

**北京时间 00:00 只切换到新一天的每日任务进度**；前一天记录、累计行动经验和账号指标仍保留。综合等级会按保留数据重新计算，近期表现数据过期或被新数据替换时可能变化，不等于记录丢失。

关闭浏览器或 X 标签页期间不会继续采集。重新打开后，只有页面实际加载到、符合统计条件的数据才可能补记。卸载扩展、清除扩展数据，或换用另一个浏览器配置文件，不能保证原记录仍可用；更新前可以先导出 JSON 备份。

## 日常使用

账号优先从 X 左侧“个人资料”入口自动识别。识别后正常在 Edge 使用 X，任务卡会跟随自动采集结果更新；首次启用前的发帖不会倒算成今天的行动。

### 怎么确认自动识别在工作

查看卡片底部的状态，点击它可展开诊断：

- **自动识别已连接**：当前登录账号与绑定账号相同，页面数据监听已成功连接。连接本身不代表已经收到新的帖子或分析页数据。
- **正在连接 / 等待登录账号**：页面正在建立监听，或尚未识别到当前登录账号。
- **账号不一致**：当前页面会暂停采集，避免把其他账号混进你的记录。
- **自动识别已暂停**：手动暂停；恢复后继续采集。
- **需要刷新页面**：扩展更新后旧页面失效，或监听／本地记录连接失败；请刷新 X。

诊断面板显示绑定账号、最近收到 X 数据响应的时间及今天自动识别的发帖／回复数量。示例预览始终标注“示例 · 未连接 X”。

### 自动采集多久会更新

下面是代码中的调度时序，**不是实际 X 网络延迟的保证**：

| 数据来源 | 更新方式 |
| --- | --- |
| 成功发布的帖子／回复 | 收到可识别的 X 响应后立即送入本机存储，不等待页面扫描计时器。还需等待 X 自身响应和本地保存完成。 |
| 当前可见的 Analytics 页面 | 首个待处理变化最早约 350 毫秒扫描；持续变化按 1.5 秒间隔节流，避免每次页面变动都重复读取。 |
| 当前可见的其他 X 页面 | 首个待处理变化最早约 350 毫秒扫描；持续变化按 3.5 秒间隔节流。 |
| 周期切换／分析页加载结束 | 先排除加载态与旧周期数值，再做稳定确认；每隔 2 秒重试，最多 3 次。页面不再变化时也会完成这轮确认，无需等到下一分钟。 |
| 静止的可见页面 | 每 60 秒兜底检查。隐藏页面暂停 DOM 扫描，已发生且可识别的页面网络响应仍按原守卫处理。 |

齿轮中的立即采集操作会重新读取**当前页面已加载的数据**并刷新任务卡；它不会要求 X 返回更多内容，也不会跳过暂停、账号匹配、加载状态和周期稳定检查。尚未完成加载或数值仍可能属于旧周期时，会继续保留上次有效读数。

如果 X 没有可识别的加载标记，且换周期后数字与旧卡片完全相同，插件会保守等待新证据；首次打开页面时，DOM 也无法绝对证明周期与所有卡片同时完成更新。实际采集速度仍受 X 响应、页面结构、浏览器节能和设备状态影响，本版尚未在真实 Edge / X 账号测量延迟。

点齿轮设置发帖、回复目标。目标设为 0 表示不设该项任务。修改目标不会增加行动经验或综合分数；手工修正行动数量会相应调整经验和行动维度。

粉丝数通过 X 已返回的本人账号信息，或打开本人主页时读取。隔天尚未读取新数据时，会标注“粉丝 · 上次”；涨跌参考日期可悬停查看，不会把跨多天变化称为今日涨粉。

曝光通过分析页读取：点齿轮中的“分析页”。只有明确属于当天、账号匹配的曝光才进入“今日曝光”。明确的 7D、2W 等周期汇总按原周期保留，满足条件时换算日均参与评级，不能当成今日曝光。例如 **2W 的 98K 是约 14 天合计 98,000，日均约 7,000**，并非今天曝光 98,000。

暂时没有今日账号曝光、但有已观察帖子的日内精确增量时，单独标为“已跟踪帖增览”；它不进入账号曝光评分。缺失值显示 `—`／“未采集”，近似值带 `≈`。

分析页的 **Checkmark followers / 认证粉丝**是关注者中带认证标记的人数；**自身蓝 V**是当前账号的认证状态，两者分别读取。认证粉丝数量进入综合评估；自身蓝 V 仅显示身份徽章，不额外加分。未能明确识别自身状态时，不根据粉丝卡片上的蓝勾或是否能打开分析页推断已开通。

## 本地宝箱与收藏

收藏页包含 12 件本地奇幻物品，名称和说明随界面语言切换。宝箱和物品提供 RPG 收集反馈，**不增加账号综合分数、行动经验或任何战力**，也没有付费购买和交易功能。

- **每日任务箱**：北京时间当天，自动识别的发帖／回复满足所有已启用目标时获得一箱，每天最多一次。目标为 0 的项目不参与；两项目标均为 0 时不发箱。手工补记可以校正任务进度，但不会触发自动达标箱。
- **等级里程碑箱**：启用收藏后，首次超过已记录的等级高点并到达 Lv.5、Lv.10、Lv.15 等每 5 级节点时获得宝箱，最高到 Lv.50。同一节点只发一次；等级下降后再次回到该等级不会重复领取。
- **历史不追发**：首次启用以现有等级为起点，不为升级前已经完成的每日任务或已到达的等级补发。导入备份本身不会产生新宝箱。
- **结果先保存**：开启后物品及开启时间写入本机记录，再展示结果。刷新 X、关闭后重开或重复点击同一箱子不会重新抽取。
- **集齐前不重复**：优先从尚未拥有的物品中随机获得一件；12 件全部集齐后，后续宝箱才可能重复，收藏里记录数量。稀有度用于物品表现，不影响账号评分。

收藏与待开箱记录包含在 JSON 备份中；同一账号恢复旧备份不会重置本机已经开启的箱子。页面内只显示收藏摘要，不需要打开独立游戏窗口。

## 综合等级：均衡成长

这是插件自定义的成长评分，不是 X 官方等级。五个维度等权，各占最多 200 分，总分最多 1000 分。

| 维度 | 输入值 | 200 分基准 |
| --- | --- | --- |
| 行动 | 本机累计行动经验，发帖 20 XP、回复 5 XP | 20,000 XP |
| 总粉丝 | 最近一次采集的总粉丝数 | 100,000 人 |
| 认证粉丝 | 最近一次采集的认证粉丝数 | 25,000 人 |
| 曝光 | 明确周期内的账号曝光日均 | 100,000 次／日 |
| 互动 | 明确周期内的账号互动日均 | 10,000 次／日 |

每维使用同一个公式：`min(200, round(200 × ln(1 + 输入值) ÷ ln(1 + 基准)))`。对数曲线让早期增长也能反映在等级上，同时每维始终封顶 200 分，单靠某一项不能占满总分。

- **来源和时效**：曝光、互动优先采用明确不少于 7 天的分析周期，按该周期天数除总量。采集时间必须在近 28 个自然日内；有结束日期时，结束日期也必须在这段范围内。明确的历史报表或过期快照不用于近期日均评分。
- **曝光日记录补充**：没有合格周期汇总时，可使用近 28 天内已采集的每日账号曝光，按实际采集天数取均值，并标为“已采集 N 天日均”。缺失日期不补零，也不宣称已覆盖完整 28 天。互动缺少合格周期数据时保持未知。
- **未知不等于 0**：未知维度的分数为“未采集”，总分只相加已知项，并显示“已采集 N/5 项”和暂定状态；不把已知项重新放大到 1000 分。明确读取到 0 的维度属于已采集，得 0 分。
- **快照不累加**：再次打开同一份报表不会重复加经验或分数；新快照替换旧快照后重新计算。粉丝和表现回落、数据过期，或手工修正记录，都可能使综合分数与等级变化。
- **等级规则**：`等级 = min(50, 1 + floor(总分 / 20))`。每 20 分一个等级，980 分起达到 Lv.50，成长条保持满格；总分仍可继续显示到 1000 分。点击等级可核对每维数值、基准、来源、时间与近似标记。

旧版本的行动记录与 XP 不会清零；从 0.5.0 开始，主等级按五维综合评估重新计算，因此它可能与旧版“每 100 XP 升一级”的等级不同。行动 XP 仍在详情和行动反馈中保留。

## 自动统计的边界

- 发帖、引用帖和回复：观察成功发布的响应，或后续加载到的本人帖子记录。相同帖子 ID 只记一次；编辑旧帖、纯转发不增加计数。线程中的自我回复属于回复。
- 手机发布的帖子：如果后来在 Edge 加载到、且在启用统计之后发布，可能自动补回；不会主动遍历手机和全部历史。
- 粉丝、认证粉丝、自身蓝 V 和分析指标随可识别的页面数据更新，不保证实时推送。分析页布局或周期不能识别时留空，不将 7D / 2W / 4W 等周期总量当成今日曝光。
- 手工补录的条目没有帖子 ID，若后来自动识别到了同一条，应使用卡片内的修正按钮校准总数。
- Edge 和 X 页面需要运行。关闭浏览器、休眠、断网或 X 改变页面／响应结构时，可能无法继续采集。
- 暂停后不接收自动新记录；恢复后从恢复时间继续计算。删除帖子不会倒扣已完成的发布行动。

扩展只观察页面已有请求，不主动调用接口拉历史，不读取请求头、Cookie、密码、令牌或私信，不代发内容。

## 备份与历史

原有数据管理页保留在 Edge 的扩展“详细信息 → 扩展选项”中，供偶尔查看历史、导出 CSV、备份／恢复 JSON 和手工校准指标使用。日常任务卡不依赖打开此页面。

该高级页顶部也可切换 **简体中文 / English**，与任务卡使用同一项语言设置。界面文字、数字／日期显示和提示随语言切换；已有复盘内容不会自动翻译。

同一浏览器配置文件中的历史会继续使用。不同浏览器／配置文件各自独立；已有历史后不直接混入另一个账号。建议定期导出 JSON 备份；卸载扩展可能清除数据。

最近最多保留 1000 条帖子指标，行动去重记录独立保留。页面内任务卡只接收展示摘要，不接收完整复盘、帖子正文与历史记录。目标修改、计数修正、暂停开关、语言切换与开箱通过受限的后台操作保存。

权限为 `storage` 和 `x.com` / `www.x.com` 访问；0.3.0 已移除 `sidePanel` 权限。卡片样式通过 Shadow DOM 隔离，不改 X 的排版。

## 开发与预览

扩展无需构建、无需安装运行依赖。开发测试：

```powershell
git clone https://github.com/soap628/x-focus-extension.git
cd x-focus-extension
npm ci
npm test
npm run preview
```

访问 `http://127.0.0.1:4317/` 查看 X 布局示意与实际任务卡。预览使用明确标注的示例数据，可模拟进度、改目标，刷新重置；不连接真实 X、不影响扩展里的真实记录。

本版最终测试数量和界面检查结果见 `VERIFICATION.md`。**当前版本尚未在你的真实 Edge / 已登录 X 页面完成联调**，页面布局与采集接口变化仍可能需要适配。

原创角色头像、雕花面板和本版新增的宝箱插画位于 `assets/`，使用内置 imagegen 生成；完整提示词与文件记录见 `assets/ARTWORK.md`。任务卡仍为 232 像素宽，运行时从扩展本地加载素材，不依赖外部图片网站。
