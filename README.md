# X Focus · RPG 任务卡（Edge 本地版 0.9.0）

打开 X，页面边缘会出现一张约 184 × 139 像素的小任务卡，默认只显示发帖和回复进度。点击右上角展开按钮可查看 232 像素宽的完整档案。无需打开扩展专门的窗口。

- 两条每日任务进度：发帖、回复。
- 原创绘画风角色头像、雕花青铜边框和暗色皮革面板，采用传统奇幻 RPG 的材质表现；不使用像素画风。
- 红色发帖进度、蓝色回复进度、金色经验条；圆形金属头像框和升级／完成反馈。
- 等级只按启用插件后的本地行动累计：发帖 +5 EXP、回复 +1 EXP，每 100 EXP 升一级。点击等级查看两项经验来源；粉丝、认证粉丝、曝光和互动只展示，不影响等级。
- 卡片显示粉丝、认证粉丝及曝光读数；账号本身的蓝 V 状态明确识别为已认证时显示专属徽章。
- 升级与任务完成有短暂光效，支持系统减少动态效果设置，无声音。
- 展开完整档案后点击右上角齿轮，直接修改每日目标、修正计数或暂停自动统计。
- 在任务卡齿轮和高级数据页切换简体中文／English，选择保存在本机；切换语言不影响数据、等级或收藏。
- 完成自动记录的每日目标、跨过新的每 5 级里程碑，可获得本地宝箱，收集 12 件奇幻物品；新增原创绘画风宝箱插画。
- 拖动顶部标题可自由移动；靠近左右边缘松手会自动贴边。设置中也可一键贴左边、贴右边或恢复自动位置。
- “−”折叠为两条任务进度，展开按钮恢复完整档案；Edge 工具栏里的扩展图标也可切换这两种模式。
- 位置和显示模式保存在本机，刷新 X、重开浏览器后保留；缩小窗口会把卡片约束在可见区域内，贴边时避开滚动条。
- 自动把完整记录保存为下载目录中的独立 JSON 存档；每天轮换 A / B 两份，另可手动保存独立文件。卸载后仍可从已写入电脑的文件恢复经验、历史和收藏。

数据留在本机；不需要云端、X API Key 或本地服务器。

## 更新已安装的扩展

如果已经从本仓库目录加载扩展，先更新该目录中的源码，再重新加载：

1. 在 Edge 地址栏输入 `edge://extensions`。
2. 找到 **X Focus · 起号日常**，点击“重新加载 / 刷新”。
3. 核对版本为 **0.9.0**，并按 Edge 提示启用新增的下载与定时任务权限。
4. **刷新所有已打开的 X 标签页**。任务卡会直接出现在页面里。
5. 展开任务卡，点**齿轮 → 本地存档与恢复 → 立即保存到电脑**；等状态显示“**文件已写入电脑**”，再用“打开备份文件位置”核对文件。

如果原来从其他文件夹安装，将 `X-Focus-v0.9.0.zip` 解压并覆盖到原来的扩展目录，再执行上述步骤。**继续使用原目录并重新加载，不要先卸载旧版**，这样可继续使用原扩展实例里的目标与记录。新增独立存档功能不会自动找回此前已经卸载丢失、又没有备份的记录。

首次安装：在 `edge://extensions` 打开“开发者模式”，选择“加载解压缩的扩展”，选中包含 `manifest.json` 的文件夹，然后刷新 X。

## 关掉浏览器后会不会重新开始

不会。目标、每日发帖／回复数量、行动经验、粉丝读数、分析数据、语言选择、宝箱收藏和面板布局保存在本机 `chrome.storage.local`，关闭浏览器、刷新 X 或重启电脑不会主动清空它们。在同一 Edge 配置文件、同一个扩展实例中重新打开 X，会继续读取这些记录。

**北京时间 00:00 只切换到新一天的每日任务进度**；前一天记录、累计行动经验、等级和账号指标仍保留。切换分析周期、更新粉丝或曝光、指标过期，都不改变经验和等级。

关闭浏览器或 X 标签页期间不会继续采集。重新打开后，只有页面实际加载到、符合统计条件的数据才可能补记。卸载扩展或清除扩展数据可能清空 `chrome.storage.local`；**已完成下载的 JSON 文件独立保存在电脑上，不随扩展卸载删除**。重装或换浏览器配置文件后，需要手动选择一次存档恢复。关浏览器前刚产生的记录可能尚未写入独立文件，因此需要重装时应先“立即保存到电脑”，确认完成后再卸载。

## 日常使用

账号优先从 X 左侧“个人资料”入口自动识别。识别后正常在 Edge 使用 X，任务卡会跟随自动采集结果更新；首次启用前的发帖不会倒算成今天的行动。

### 怎么确认自动识别在工作

先展开完整档案，查看卡片底部的状态，点击它可展开诊断：

- **自动识别已连接**：当前登录账号与绑定账号相同，页面数据监听已成功连接。连接本身不代表已经收到新的帖子或分析页数据。
- **正在连接 / 等待登录账号**：页面正在建立监听，或尚未识别到当前登录账号。
- **账号不一致**：当前页面会暂停采集，避免把其他账号混进你的记录。
- **自动识别已暂停**：手动暂停；恢复后继续采集。
- **需要刷新页面**：扩展更新后旧页面失效，或监听／本地记录连接失败；请刷新 X。

精简卡片顶部的小圆点也可直接打开诊断。诊断面板显示绑定账号、最近一次成功记入行动的时间及今天自动识别的发帖／回复数量；“监听已连接”不等于已经记到帖子。若页面替换了监听器，会提示实时监听待恢复，而不是继续显示正常。示例预览始终标注“示例 · 未连接 X”。

### 漏记后的恢复

先在 `edge://extensions` 核对版本为 **0.9.0**，重新加载扩展并刷新 X，然后打开自己的主页，让近期帖子加载；回复可打开“回复”标签。扩展会处理这些页面实际返回的本人帖子，补记启用记录时间之后的行动；同一帖子通过多个渠道被发现，也只记一次。未加载到或无法确认类型的内容不会猜作发帖。原先漏掉的具体帖子是否补回，需要核对当前账号的实际计数。

本版保留 0.8.1 的长文 `notetweet_create` 成功结果识别。页面身份识别较晚时，只暂存已清洗的成功发布候选，确认同一账号后释放；暂停或切换账号会取消待处理数据。后台暂时未确认保存时，最多按 2 / 5 / 10 秒间隔重试，随后等待下次握手；队列最多 30 条、5 分钟。监控仍不使用云端、额外请求权限或后台主动抓取。

另有发布成功提示兜底：在唯一可见编辑器明确提交后，必须出现新的成功提示、本人帖子链接和符合提交时间的帖子 ID，才可记账。单纯点击发布、失败、旧提示、多编辑器线程或无法确认的类型均不计数；不保存草稿。回复仍只得 1 EXP。

### 拖动、折叠与贴边

默认精简模式只保留发帖、回复两条进度。点击右上角双箭头展开完整档案，点击“−”折回小卡；两种模式使用同一份数据，显示切换不改变经验或采集。

按住顶部“每日委托／冒险档案”区域拖动，松手后保存位置。距离左边或右边 24 像素内会自动停靠，留出 4 像素边距并避开浏览器滚动条。点击设置、展开或折叠按钮不会触发拖动。拖动中按 Escape 可取消；焦点离开窗口或指针取消也不保存未完成的拖动。

完整档案的齿轮设置中提供“贴左边 / 贴右边 / 自动位置”。顶部也可用 Tab 聚焦后按方向键移动，每次 10 像素，按住 Shift 每次 40 像素。缩小窗口或展开较高面板时会调整可见位置，避免按钮跑出屏幕；自由位置按可用区域的比例保存。

### 自动采集多久会更新

下面是代码中的调度时序，**不是实际 X 网络延迟的保证**：

| 数据来源 | 更新方式 |
| --- | --- |
| 成功发布的帖子／回复 | 收到可识别的 X 响应后立即送入本机存储，不等待页面扫描计时器。还需等待 X 自身响应和本地保存完成。 |
| 当前可见的 Analytics 页面 | 首个待处理变化最早约 350 毫秒扫描；持续变化按 1.5 秒间隔节流，避免每次页面变动都重复读取。 |
| 当前可见的其他 X 页面 | 首个待处理变化最早约 350 毫秒扫描；持续变化按 3.5 秒间隔节流。 |
| 周期切换／分析页加载结束 | 先排除加载态与旧周期数值，再做稳定确认；每隔 2 秒重试，最多 3 次。页面不再变化时也会完成这轮确认，无需等到下一分钟。 |
| 静止的可见页面 | 每 60 秒兜底检查。隐藏页面暂停 DOM 扫描，已发生且可识别的页面网络响应仍按原守卫处理。 |

齿轮中的立即采集操作会重新读取**当前页面已加载的数据**并刷新任务卡；它不会要求 X 返回更多内容，也不会跳过暂停、账号匹配、加载状态和周期稳定检查。尚未完成加载或数值仍可能属于旧周期时，会继续保留上次有效读数。

如果 X 没有可识别的加载标记，且换周期后数字与旧卡片完全相同，插件会保守等待新证据；首次打开页面时，DOM 也无法绝对证明周期与所有卡片同时完成更新。实际采集速度仍受 X 响应、页面结构、浏览器节能和设备状态影响，本版尚未在真实 Edge / X 账号测量延迟。

点齿轮设置发帖、回复目标。目标设为 0 表示不设该项任务。修改目标不会增加经验；手工修正行动数量会按发帖 5 EXP、回复 1 EXP 同步校正经验和等级。

粉丝数通过 X 已返回的本人账号信息，或打开本人主页时读取。隔天尚未读取新数据时，会标注“粉丝 · 上次”；涨跌参考日期可悬停查看，不会把跨多天变化称为今日涨粉。

曝光通过分析页读取：点齿轮中的“分析页”。只有明确属于当天、账号匹配的曝光才进入“今日曝光”。明确的 7D、2W 等周期汇总按原周期保留，满足条件时换算日均用于展示，不能当成今日曝光。例如 **2W 的 98K 是约 14 天合计 98,000，日均约 7,000**，并非今天曝光 98,000。所有这些指标都不产生 EXP。

暂时没有今日账号曝光、但有已观察帖子的日内精确增量时，单独标为“已跟踪帖增览”；它不能替代账号曝光。缺失值显示 `—`／“未采集”，近似值带 `≈`。

分析页的 **Checkmark followers / 认证粉丝**是关注者中带认证标记的人数；**自身蓝 V**是当前账号的认证状态，两者分别读取。认证粉丝数量只作展示，自身蓝 V 仅显示身份徽章，都不增加经验。未能明确识别自身状态时，不根据粉丝卡片上的蓝勾或是否能打开分析页推断已开通。

## 本地宝箱与收藏

收藏页包含 12 件本地奇幻物品，名称和说明随界面语言切换。宝箱和物品提供 RPG 收集反馈，**不增加经验或任何战力**，也没有付费购买和交易功能。

- **每日任务箱**：北京时间当天，自动识别的发帖／回复满足所有已启用目标时获得一箱，每天最多一次。目标为 0 的项目不参与；两项目标均为 0 时不发箱。手工补记可以校正任务进度，但不会触发自动达标箱。
- **等级里程碑箱**：启用收藏后，首次超过已记录的行动等级高点并到达 Lv.5、Lv.10、Lv.15 等每 5 级节点时获得宝箱。同一节点只发一次；手工纠错使等级下降后再次回到该等级不会重复领取。
- **历史不追发**：首次启用以现有等级为起点，不为升级前已经完成的每日任务或已到达的等级补发。导入备份本身不会产生新宝箱。
- **结果先保存**：开启后物品及开启时间写入本机记录，再展示结果。刷新 X、关闭后重开或重复点击同一箱子不会重新抽取。
- **集齐前不重复**：优先从尚未拥有的物品中随机获得一件；12 件全部集齐后，后续宝箱才可能重复，收藏里记录数量。稀有度用于物品表现，不影响经验。

收藏与待开箱记录包含在 JSON 备份中；同一账号恢复旧备份不会重置本机已经开启的箱子。页面内只显示收藏摘要，不需要打开独立游戏窗口。

## 行动等级：发帖 5 EXP，回复 1 EXP

首次启用且没有已有行动记录时，从 **Lv.1、0 EXP** 开始。只有插件记录的发帖和回复增加经验；不会把安装前的全部 X 历史折算成等级。

- **累计经验**：`EXP = 本机累计发帖数 × 5 + 本机累计回复数 × 1`。
- **等级**：`Lv = 1 + floor(EXP / 100)`，每 100 EXP 升一级，不设 Lv.50 封顶。
- **经验条**：显示当前级的 `EXP % 100 / 100 EXP`。例如 19 帖和 4 条回复共 99 EXP，为 Lv.1；再回复一次达到 Lv.2、0/100 EXP，累计经验仍为 100。
- **保存和去重**：刷新、重开浏览器、跨日不会重置累计经验；同一条成功发布的帖子 ID 只记录一次。安装前的旧帖、编辑旧帖和纯转发不计入新行动。
- **账号指标独立展示**：粉丝、蓝 V、认证粉丝、曝光和互动不参与经验或等级。打开 7D、2W 等不同分析周期，不会升降等级或触发等级宝箱。
- **手工纠错**：修正已记录的发帖／回复条数时，经验按同一公式校正；下调条数可能降低等级。目标设置不影响经验。

升级到 0.7.0 时保留已有行动条数，并按 5／1 的新规则重算。旧版由账号指标推高的等级不再沿用，已有收藏保留；规则迁移本身不发宝箱。后续按行动等级继续解锁新的里程碑。

## 自动统计的边界

- 发帖、引用帖和回复：观察成功发布的响应，或后续加载到的本人帖子记录。相同帖子 ID 只记一次；编辑旧帖、纯转发不增加计数。线程中的自我回复属于回复。
- 手机发布的帖子：如果后来在 Edge 加载到、且在启用统计之后发布，可能自动补回；不会主动遍历手机和全部历史。
- 粉丝、认证粉丝、自身蓝 V 和分析指标随可识别的页面数据更新，不保证实时推送。分析页布局或周期不能识别时留空，不将 7D / 2W / 4W 等周期总量当成今日曝光。
- 手工补录的条目没有帖子 ID，若后来自动识别到了同一条，应使用卡片内的修正按钮校准总数。
- Edge 和 X 页面需要运行。关闭浏览器、休眠、断网或 X 改变页面／响应结构时，可能无法继续采集。
- 暂停后不接收自动新记录；恢复后从恢复时间继续计算。删除帖子不会倒扣已完成的发布行动。

扩展只观察页面已有请求，不主动调用接口拉历史，不读取请求头、Cookie、密码、令牌或私信，不代发内容。

## 备份与历史

### 独立存档保存在什么地方

本机记录仍立即写入扩展的 `chrome.storage.local`。0.9.0 另增加独立的**全量 JSON 文件存档**，默认开启自动保存，位置是浏览器设置的下载目录下：

```text
Downloads / X-Focus / <账号> /
  x-focus-2026-09-26-<安装标识>-auto-A.json
  x-focus-2026-09-26-<安装标识>-auto-B.json
```

这里的 `Downloads` 指 Edge 当前下载目录，不一定是系统默认“下载”文件夹。每个文件都包含一份完整记录，可以单独恢复，无需同时收集多个文件。

- **自动保存**：有实际记录后，数据变化约合并 1 分钟再保存；仅账号绑定、监听心跳或相同读数的时间更新不会不断生成空档或重复存档。每 5 分钟另作维护检查，失败后有约 5 分钟重试间隔。浏览器调度、下载设置、休眠或关闭浏览器都可能延后写入，这些时间不是完成时限保证。
- **每天两档**：每个账号、每个日期使用 A / B 两个自动存档，成功写入后才轮换到另一档；后续保存更新同日旧槽，不会每分钟新增文件。历史日期的存档不会自动删除，需要时可自行整理。
- **重装隔离**：每次全新安装会生成独立安装标识，重装后的自动存档不会覆盖旧安装留下的文件。更新原目录并重新加载会沿用原标识。
- **手动保存**：点击“立即保存到电脑”生成带时间戳的独立文件，不占用 A / B 自动存档，也不覆盖此前手动文件。
- **完成状态**：“已提交保存”或“正在保存文件”不代表写入完成。应等到“文件已写入电脑”，再使用“打开备份文件位置”查看实际文件；失败会显示错误，已有发帖和回复仍按原流程记账。

独立文件包含每日行动、累计经验所依据的全部条数、原统计开始时间（`tracking.startedAt`）、帖子 ID 去重记录、目标、指标、复盘、已开与待开宝箱、语言和任务卡布局。保存文件本身不增加 EXP，也不发放宝箱；恢复后重放已记录的帖子不会再次获得经验。最近最多保留 1000 条帖子指标缓存，行动去重记录独立保留。

### 重装后如何恢复

1. 安装扩展并刷新 X，展开任务卡，点**齿轮 → 本地存档与恢复 → 恢复存档**。也可从 Edge 扩展“详细信息 → 扩展选项”进入。
2. 在下载目录的 `X-Focus/<账号>/` 中，按**修改时间**寻找包含原有进度的 JSON 文件。A / B 文件名不表示谁更新；重装后也可能出现另一安装标识的新文件，应核对文件内容摘要。
3. 核对恢复窗口中的**账号、记录天数、发帖、回复、累计 EXP 与收藏摘要**。单个导入文件上限为 **16 MiB（16 × 1024 × 1024 字节）**，原有格式与记录数量校验仍生效。
4. 如果当前扩展已有记录，先点击“下载当前备份”，等保护备份完成后再点击“替换并恢复”；空记录的新安装可直接核对并确认。恢复会替换当前记录；不同账号不会合并，同账号已经开过的宝箱结果仍受到保留保护。
5. 恢复完成后继续浏览 X。原始统计起点和去重记录随存档恢复，后续新发帖仍为 +5 EXP、新回复为 +1 EXP。

**重装后需要手动选择一次文件**。扩展不能自动读取电脑上任意已有文件，也不能恢复尚未完成写入或已经被删除的存档。以上是功能与操作说明，不代表当前设备已经生成可用备份；请以界面的完成状态和实际文件为准。

### 历史管理与权限

数据管理页保留查看历史、导出 CSV、备份／恢复 JSON 和手工校准指标。日常任务卡与自动存档不依赖一直打开此页面；CSV 用于查看日记录，完整恢复应使用 JSON。

该高级页顶部也可切换 **简体中文 / English**，与任务卡使用同一项语言设置。界面文字、数字／日期显示和提示随语言切换；已有复盘内容不会自动翻译。

同一浏览器配置文件中的历史会继续使用。不同浏览器／配置文件的扩展存储各自独立，可通过已保存的 JSON 文件迁移；没有云端同步。

页面内任务卡只接收展示摘要，不接收完整复盘、帖子正文与历史记录。目标修改、计数修正、暂停开关、语言切换与开箱通过受限的后台操作保存。

权限为 `storage`、`downloads`、`alarms` 和 `x.com` / `www.x.com` 访问。0.9.0 新增 `downloads`，用于保存 JSON、确认下载完成和定位存档；新增 `alarms`，用于安排合并保存、维护与失败重试。文件留在本机，不上传服务器。0.3.0 已移除 `sidePanel` 权限。卡片样式通过 Shadow DOM 隔离，不改 X 的排版。

## 开发与预览

扩展无需构建、无需安装运行依赖。开发测试：

```powershell
git clone https://github.com/soap628/x-focus-extension.git
cd x-focus-extension
npm ci
npm test
npm run preview
```

访问 `http://127.0.0.1:4317/` 查看 X 布局示意与实际任务卡。预览使用明确标注的示例数据，可模拟进度、改目标；刷新会重置示例行动数据，位置和模式单独保存在预览站点本地，便于验证重载。点击“重置演示”可一起重置布局。不连接真实 X，不影响扩展里的真实记录。

本版最终测试数量和界面检查结果见 `VERIFICATION.md`。**当前版本尚未在你的真实 Edge / 已登录 X 页面完成联调**，页面布局与采集接口变化仍可能需要适配。

原创角色头像、雕花面板和宝箱插画位于 `assets/`，使用内置 imagegen 生成；完整提示词与文件记录见 `assets/ARTWORK.md`。完整档案宽 232 像素、精简任务卡宽 184 像素，运行时从扩展本地加载素材，不依赖外部图片网站。
