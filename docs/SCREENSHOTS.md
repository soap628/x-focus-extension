# 截图来源与复现

这些图片用于 GitHub README 的产品展示，拍摄于 2026-09-27，对应 X Focus **v0.9.1**。

## 来源与范围

- 所有图片均通过浏览器渲染仓库内的离线演示页面后截取，使用实际的任务卡组件和设置页。
- 这是本地浏览器预览，不是已登录 Edge / X 的运行截图。背景是模拟的 X 布局，账号读数、发布记录、经验和收藏来自演示数据，不可用来证明真实账号的统计结果或采集延迟。
- 任务卡截图中的完整档案标有“示例 · 未连接 X”。精简卡片不显示完整状态文字，因此 README 统一说明所有图片均为演示。
- 全景图保留原始浏览器画面；面板特写只按组件边界裁切，并保留约 10 CSS 像素的周边留白。没有重绘、替换文字或改变截图中的数值。图片像素尺寸可能受浏览器截图缩放影响，与组件的 CSS 尺寸略有差异。
- 设置页的文件保存功能在预览中不可用。截图保留这一提示，不代表已经保存了可恢复的 JSON 文件。

## 复现截图

在仓库根目录运行：

```sh
npm run preview
```

1. 打开 `http://127.0.0.1:4317/?demo=1`。页面上的工具栏可重置示例、模拟发帖和回复。首次拍摄前先重置示例。
2. 精简模式截图只截取右侧两条任务进度；点击卡片右上角展开按钮查看完整档案。
3. 全景与任务卡特写使用约 1920 × 1080 CSS 像素的浏览器视口。原始画面完整截取后，再裁出对应面板。
4. 在初始示例上模拟发帖一次、回复四次，完成两项每日目标；进入收藏并开启宝箱。物品随机，因此重新拍摄时可能得到不同物品。
5. 打开 `http://127.0.0.1:4317/sidepanel.html?demo=1#backup`，在约 1280 × 720 CSS 像素的视口下截取“本地存档与恢复”卡片。保留预览不能自动写文件的提示。

预览仅用于开发和展示。安装后的扩展不需要运行本地预览服务器；实际备份与恢复行为见 [README](../README.md#备份与历史)。
